CSS Layouts

Un layout en CSS es la estructura o esquema visual que define cómo se organizan, alinean y distribuyen los elementos (como textos, imágenes, botones y barras de navegación) dentro de una página web.

Animaciones

Las animaciones en CSS son efectos visuales que permiten cambiar el estilo de un elemento HTML de forma gradual a lo largo del tiempo, sin necesidad de usar JavaScript.

Sass

¿Qué es CSS?

CSS (Cascading Style Sheets u Hojas de Estilo en Cascada) es un lenguaje de diseño gráfico que se utiliza para definir la apariencia visual de los documentos escritos en HTML o XML.

¿Qué aprenderé en este curso?

Temas principales que se estudian • Fundamentos y sintaxis: Qué es CSS, cómo vincularlo a un documento HTML y cómo escribir reglas básicas con selectores, propiedades y valores. • Cascada, herencia y especificidad: Las reglas que determinan qué estilos se aplican cuando hay varias instrucciones para un mismo elemento. • Modelo de caja (Box Model): Cómo funcionan los márgenes (margins), los bordes (borders), el relleno (padding) y el contenido de cada elemento. • Tipografía y color: Cómo cambiar tipos de letra, tamaños, pesos, colores, degradados y sombras. • Sistemas de diseño y maquetación (Layout): • Posicionamiento (positioning) y flotados. • Flexbox: Para alinear y distribuir elementos en una sola dimensión (filas o columnas). • CSS Grid: Para crear diseños complejos en dos dimensiones (rejillas o cuadrículas). • Diseño responsivo (Responsive Design): Uso de consultas de medios (media queries) para que las páginas se adapten bien a teléfonos móviles, tabletas y computadoras. • Pseudoclases y pseudoelementos: Estilizar estados como pasar el ratón por encima (hover), elementos activos o partes específicas de un texto (focus, nth-child, etc.). • Transiciones y animaciones: Dar movimiento, efectos visuales y dinamismo a la interfaz. • Buenas prácticas: Metodologías como BEM para organizar el código en proyectos grandes.

¿Qué es CSS GRID?

CSS Grid (o CSS Grid Layout) es un sistema de maquetación web en dos dimensiones (filas y columnas) que permite organizar el diseño de una página web de forma sencilla, ordenada y adaptable.
